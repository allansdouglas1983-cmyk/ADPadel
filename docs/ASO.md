## Positioning gap to own
No incumbent does iOS + Android + Apple Watch + Wear OS with a strong
social/Wrapped loop and Americano/Mexicano depth. Say so in copy + screenshots.

## Screenshots (the shared card is the primary marketing asset)
1. Live scoreboard mid-match (dark, glanceable).
2. The shareable match card ("your bragging rights").
3. Americano live leaderboard.
4. Partner-chemistry stats.
5. Apple Watch + Wear OS scoring.
6. Season Wrapped.

## Launch channels (organic-first)
- The share/claim loop — seed by getting a few clubs running Americano nights.
- r/padel and club WhatsApp/Facebook groups (offer free Pro to early clubs).
- Padel clubs (free Americano organiser for managers → multi-user bursts).
- Day-one cross-promo from the founder's existing app audience.
- Instagram/TikTok clips of the card / Wrapped reveal.

## Pre-launch smoke tests
1. Landing page with the card mockup + email capture + "notify me".
2. Post the card mockup to r/padel and club groups for pull + feedback.
3. AppTweak/Sensor Tower keyword-volume check for "padel score" / "marcador pádel".

## Metrics that decide the plan
Install→activation (first match scored), viral coefficient, trial-start,
trial→paid, annual mix. If viral coefficient < 0.2 by month 3 → add referral
rewards + paid ASO. If conversion < 2% → tighten the free-history cap.
